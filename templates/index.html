Key Capabilities

Engineered for Academic Excellence

Built following professional software engineering principles and layered MVC architecture.

Automated Timer & Auto-Submit

Calculates remaining time server-side with client-side visual synchronization. Automatically finalizes and submits answers when the timer runs out.

Server-Side Scoring & Security

Zero trust for browser-submitted scores. Answers are evaluated securely on the backend against database keys, preventing cheating and DOM inspection.

Interactive Question Palette

Students can review answered vs unanswered questions dynamically with color-coded badges, navigate back and forth, and confirm before submission.

Role-Based Access Control

Spring Security enforces separation between Administrator and Student roles with BCrypt password hashing and custom authentication filters.

Robust Relational Database

Strict relational normalization in MySQL 8.0 with foreign keys, cascading constraints, and JPA Hibernate ORM mapping for clean data integrity.

Instant Analytics & History

Provides students with detailed scorecards and question-by-question explanations, while giving administrators aggregate class performance reports.
